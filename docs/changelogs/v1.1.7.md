## Fixes

* **fix(platform): migrate ACME HTTP-01 to ingressClassName API**: `ClusterIssuer`s (`letsencrypt-prod`, `letsencrypt-stage`) previously hardcoded `http01.ingress.class: nginx`, pointing at an ingress class that does not exist on standard Cozystack installs (real classes are named after tenants, e.g. `tenant-root`). ACME certificate issuance only worked because every requesting ingress overrode the issuer via the deprecated `acme.cert-manager.io/http01-ingress-class` annotation. Both the issuer and ingress templates are now switched to the modern cert-manager API (`ingressClassName` field in the ClusterIssuer and `acme.cert-manager.io/http01-ingress-ingressclassname` annotation on ingresses), with the ingress class parameterized from `_cluster.expose-ingress` (default `tenant-root`). Mixing the old and new APIs would trigger a cert-manager validation error, so the migration is atomic across all 9 affected ingress templates ([**@myasnikovdaniil**](https://github.com/myasnikovdaniil) in #2436, backport #2439).

## Documentation

* **[website] Document tenant namespace layout and parent/child derivation**: New section in the Tenant System guide explains how workload namespace names are constructed and how downstream integrations should walk the tenant hierarchy ([**@lexfrei**](https://github.com/lexfrei) in cozystack/website#479).

* **[website] Document the checkbox-then-edit-CR customization pattern for tenant services**: New *Customizing Tenant Services* section covers how to configure tenant-level services (etcd, monitoring, ingress, seaweedfs) by enabling the checkbox and then editing the generated CR ([**@lexfrei**](https://github.com/lexfrei) in cozystack/website#485).

* **[website] Fix 14 broken links and stale talm anchor across v1 docs**: Resolves broken cross-references and an outdated anchor in the talm documentation section ([**@lexfrei**](https://github.com/lexfrei) in cozystack/website#486).

* **[website] Rewrite external-apps guide for ApplicationDefinition API**: Replaces outdated `CozystackResourceDefinition` references with the current `ApplicationDefinition` API and updates the guide to reflect current conventions ([**@kitsunoff**](https://github.com/kitsunoff) in cozystack/website#488).
